# LIFELINE Shelf · 音乐工程资料库

当前版本：**v0.8.0 Alpha** · Apple Silicon · macOS 13+。
[下载 v0.8.0 Alpha](https://github.com/YPDDW1908/CubaseShelf/releases/tag/v0.8.0) · [全部版本](https://github.com/YPDDW1908/CubaseShelf/releases)

独立开发的原生 macOS 应用，参考 SessionCrate 公开介绍中的工程管理需求，面向 Cubase 工程重新实现。未复用其二进制、图标或源码。本应用不是 Steinberg 或 CRAT 的官方产品。

## 品牌与外观

软件已更名为 LIFELINE Shelf。应用图标和侧栏标志使用用户提供的 LIFELINE 原图，保留原始标志，增加圆角底板、透明留白和多尺寸图标。浅色/深色模式自动跟随 macOS；浅色采用暖白、灰青与深青绿色，深色采用较亮石墨灰与浅青绿色。

为兼容旧版收藏、备注、文件权限书签及资料库，应用标识和原有资料库目录保持不变。无需重新导入；建议退出旧版后启动新版，避免两个版本同时修改同一资料库。GitHub 仓库地址保留 CubaseShelf，软件名称为 LIFELINE Shelf。

## 开始使用

1. 退出旧版本，解压后打开 LIFELINE Shelf.app；可拖入“应用程序”。
2. 点击“添加工程文件夹…”，选择包含 CPR 的工程目录或包含多个工程的父目录。ZIP 需要先解压。
3. 每个工程自己的 Mixdown／Bounce／Export／Render 音频自动进入“导出试听”，名称无需匹配 CPR；支持子目录。外部参考音频可手动关联。
4. 点击音频名称加载波形与响度分析，播放按钮开始试听。同工程切换音频保持绝对播放时间。
5. “工程信息 · 自动读取”显示所选 CPR 的信息；“在 Cubase 中打开”交给配置的 Cubase 应用载入。

用户已反馈 Cubase 15 实际打开工程测试通过。开发机版本为 15.0.30.287，尚未覆盖其他 Cubase 版本。

## 工程管理

- CPR 按所在文件夹归组为版本；根目录及 Auto Saves 等备份目录中的 BAK 单独统计。
- 收藏、制作状态、模板标记、备注、手动 BPM 备注、搜索及排序。
- 按工程位置筛选，可叠加搜索、收藏和制作状态；支持最近工程、缺少试听、试听较旧及离线工程筛选。
- 自动刷新监听文件变化，合并连续事件；支持开关和 ⌘R。离线位置每 30 秒尝试恢复，正常位置每 5 分钟补扫，返回应用、磁盘挂载和唤醒时也会检查。
- 离线位置保留索引、收藏和备注，可继续编辑。缓存不是工程或音频备份，原文件不可访问时不能打开／播放。
- 自动迭代评分按当前唯一 BAK 数量计算：0 个无星，1–4 个 1 星，5–9 个 2 星，10–19 个 3 星，20–49 个 4 星，50 个及以上 5 星。分数反映迭代活跃度，不评价音乐质量；轮换或删除备份会改变评分。旧手动评分仅为兼容保留。

## 工程移动与资料迁移

- 新版成功扫描一次后，会记录文件系统身份和 CPR 内容摘要。扫描范围内的移动／重命名可自动匹配，迁移备注、收藏、阶段、模板、手动 BPM 以及工程目录内手动关联的音频路径。
- 同一磁盘通过目录身份匹配；跨磁盘用未改变的 CPR 内容匹配。只有原路径已消失且匹配唯一时才自动迁移。跨磁盘匹配还要求旧父目录可读取，以免把离线磁盘上的原工程误认成副本。
- 移到扫描范围之外时，需先添加新位置。带有资料的旧索引会保留为找回记录，支持重启后恢复。
- 不明确时，使用工程详情的“重新定位…”或侧栏“找回移动工程资料”，选择直接包含 CPR 的新目录。目标已有资料时不会覆盖。
- 每次实际迁移前，在资料库目录写入 `library-before-move-<UUID>.json` 恢复副本。迁移只更改资料库，不移动或修改工程文件。
- v0.3 及更早的缓存没有身份信息；若升级前已经移动工程，需手动重新定位。复制且原文件仍存在时不会自动转移资料。不会仅按工程名字匹配。

## 音频分析与试听

加载音频后在后台分析，结果显示在底部播放器：

- LUFS-I：K 加权、400 ms 分块、100 ms 步长，绝对和相对双重门限。
- LRA：3 秒窗口、100 ms 步长、10%–95% 百分位范围。
- True Peak：8× FIR 插值峰值；同时显示原始 Sample Peak。
- LUFS/LRA 支持单声道、立体声及布局明确的 5.1；其他布局显示未知。True Peak 支持 44.1 kHz 及以上。静音、不足 400 ms 的综合响度、不足 3 秒的 LRA 显示“—”。
- 30 组精度对照完成，包含 FFmpeg、pyloudnorm 和 SciPy 16× 插值；具体误差及保留差异见 [音频精度验证](音频精度验证.md)。仍不等于完整 ITU/EBU 符合性认证。短于 60 秒的 LRA 标记稳定性有限。
- WAV、AIFF、FLAC、MP3、M4A、CAF 的实际解码依赖 macOS；不是直接渲染 CPR。支持可选试听响度对齐，不更改原音频。

避免把 Audio、Edits、Images、Track Pictures、Stems、分轨等录音／素材目录误当导出，不跟随目录符号链接。Mixdown 内独立音轨仍可能被识别为试听，请将分轨放在 Stems 子目录。音频时间早于 CPR 时显示时间戳提示，不判断内容是否过期。

## 工程信息读取

选中 CPR 后自动显示保存的 Cubase 版本、起始 BPM、速度事件值、去重通道名和插件引用名。切换 CPR 版本会读取对应文件，最新版的识别结果随索引缓存。

这是针对已观察结构的实验性只读识别，不是完整 CPR 解析器。未知结构不猜测 120 BPM，也不把插件预设的 BPM 当工程速度。通道名包含输入／输出且同名会去重，不等于精确轨道总数；插件引用不等于当前启用或已安装的插件。未解析完整路由、插件参数、轨道事件。超过 128 MB 的 CPR 跳过信息解析。

手动 BPM 留作用户备注，不覆盖自动读取值。项目文件保持原样。

## 资料与分发

资料库：`~/Library/Application Support/CubaseShelf/library.json`。包含位置书签、索引和用户资料，建议备份；移动恢复副本也保存在这里。应用不上传工程或音频。公开源码／安装包不包含私人测试素材或资料库。

没有删除工程功能。移除工程位置／取消音频关联均不删除磁盘文件。模板目前只是标签，不复制文件。

构建采用本机临时签名，未做 Apple Developer ID 签名／公证。未充分覆盖 Intel、其他系统、大量工程、网络磁盘或实体外置磁盘拔插。

## 源码与验证

安装 Xcode Command Line Tools 后：

```sh
bash build.sh
bash test.sh
```

无外部运行时依赖，Swift 6.1.2 的 Swift 5 模式，构建目标 `arm64-apple-macosx13.0`。可用 `CUBASESHELF_BUILD_DIR` 指定编译缓存，用 `CUBASESHELF_APP_PATH` 指定 app 输出。

默认测试 162 项；私有真实样本只读检查额外 6 项，共 168 项通过。默认测试只生成合成样本。可自行运行：

```sh
bash test.sh /absolute/path/to/project --filesystem-only
```

不加 `--filesystem-only` 会额外测试音频解码；受限终端可能禁止系统音频服务，此时在桌面验证。详见 [验证记录](验证记录.md)。

## 试听响度对齐（v0.5）

底部打开“试听响度对齐”，选择 −23、−18 或 −14 LUFS；默认目标 −18，开关默认关闭。分析完成前等待，不先播放未经对齐的原音。

按原始综合响度计算静态增益；峰值上限 −1 dBTP，另留 0.3 dB 测量余量；最多提升 +12 dB。触及上限时显示预计响度和“未达到目标”，不使用压缩器强行达标。较安静的音频可以选择 −23 LUFS，与较响的版本一起比较。

为了支持正增益，应用生成临时 Float32 CAF 试听文件。原文件不修改，切换和正常退出时清理当前缓存；强制结束可能留下系统临时文件。播放／暂停、定位和同工程版本切换沿用原行为。底部分析指标始终表示原音，增益和预计对齐响度单独显示；系统音量和试听音量不计入 LUFS 目标。

静音、过短、未知声道布局、无法测得 True Peak 或分析失败时不自动退回原音播放，可关闭开关自行试听。准备对齐时停止会取消待播放意图。


## v0.7 工程信息与音频分析

- CPR 增加工程音频属性（采样率、位深）、起始拍号和带小节位置的拍号事件。严格匹配字段及类型；冲突或未知结构不猜测，不默认 4/4。
- 解析器版本升级后会重新读取在线工程；离线工程继续保留已有缓存。工程属性与某一 Mixdown 的实际导出参数可以不同。
- 音频分析增加最大瞬时（400 ms）、最大短时（3 s）响度，以及原文件 PCM 位深；压缩音频不会把解码后的 Float32 误标为原文件位深。
- 支持明确声明声道布局的 5.1 响度分析：根据实际声道顺序定位 LFE 和环绕声道。LFE 不计入响度，但计入峰值。未识别布局不按声道数猜测。
- LRA 计算保留不足 100 ms 的文件尾部，并计算补静音时滤波器衰减；LUFS-I 不包含这段补静音。
- 无效采样显式提示，禁用相关分析及响度对齐；满刻度采样提示不等于确认已发生削波失真。
- 同路径音频重新导出后，重新选择会检查实际修改时间和大小，更新分析缓存。

详见 [v0.7 验证与限制](工程信息与音频验证.md)。精确轨道计数、轨道类型、路由和插件当前启用状态仍未可靠实现；本版没有增加自动调用 Cubase 渲染的功能。
