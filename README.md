# CubaseShelf · Cubase 工程资料库

独立开发的 macOS 原生应用，参考 SessionCrate 公开介绍中的工程管理需求，面向 Cubase 工程重新实现。没有修改或复用 SessionCrate 的二进制、图标或源码。本应用不是 Steinberg 或 CRAT 的官方产品。

[下载 v0.1.0 Alpha](https://github.com/YPDDW1908/CubaseShelf/releases/tag/v0.1.0) · Apple Silicon · macOS 13+

## 开始使用

1. 双击 `CubaseShelf.app`，也可以将它拖到“应用程序”后打开。
2. 点击左下角“添加工程文件夹…”，选择已解压的 Cubase 工程目录，或包含多个工程文件夹的父目录。请先解压 ZIP。
3. 选中工程。`Mixdown` 文件夹内的音频会自动出现在“导出试听”；其他位置的混音可通过“关联音频…”添加。
4. 点击音频名称加载波形，点击播放按钮试听。拖动底部波形可定位时间。同一工程中切换音频会保持绝对播放时间；暂停时切换仍保持暂停。
5. 点击“在 Cubase 中打开”打开选中的 `.cpr` 版本。默认查找 `/Applications/Cubase 15.app`；安装在其他位置时用侧栏“选择 Cubase 应用…”。

测试环境中的 Cubase 版本为 **15.0.30.287**。应用面向 Apple Silicon、macOS 13 或更新版本；目前实测覆盖有限，尚未验证其他系统与 Cubase 版本。

## 已实现

- 多个本地／外置硬盘工程位置；扫描 `.cpr`，同一目录内的工程文件归组为版本。
- 自动备份统计：工程根目录和 `Auto Saves` 等备份目录中的 `.bak`；可在 Finder 中定位，不自动恢复或覆盖。
- 收藏、五星评分、制作状态、模板标签、备注与手动 BPM。
- 搜索工程、备注、工程版本和导出文件名；按日期、名称、评分排序。
- 最近 30 天、收藏、模板、制作阶段、缺少试听、试听较旧筛选。
- 自动发现 Mixdown、Bounce、Export、Render 等导出目录中的音频。
- 工程根目录只自动匹配与工程／版本同名或常见版本后缀的音频，避免导入根目录的参考曲。其他音频可以手动关联。
- 排除 `Audio`、`Edits`、`Images`、`Track Pictures`、`Stems`、`分轨` 等目录，不跟随符号链接。导出目录内任意命名的单独音轨仍可能被识别为试听，请将分轨放在独立 `Stems` 子目录。
- WAV、AIFF、FLAC、MP3、M4A、CAF 候选音频；实际解码依赖 macOS 音频框架。本次已验证提供的 MP3 和 WAV。
- 原始 PCM 峰值波形、播放／暂停／停止、拖动定位、音量和音频时长／声道／采样率。
- 同工程 A/B 试听切换保持绝对时间；目标音频较短时限制在目标时长内，不自动补齐或循环。
- 本地 JSON 资料库、原子写入、文件位置书签、启动扫描和 ⌘R 手动刷新。

## 当前边界

- 这是 **0.1 Alpha 基础版**，不是原软件的完整复刻。
- 不解析 CPR 内部的 BPM、轨道数、插件信息。BPM 为手动备注，不影响工程。
- 暂无 LUFS／True Peak／LRA 分析、响度对齐、菜单栏播放器或自动目录监听。
- 不渲染 Cubase 工程，试听的是已经导出的音频；也不自动补偿导出音频的前置静音。
- 模板功能是标签分类，不自动复制工程或素材。同一文件夹内的不相关 CPR 也会归为一组，建议每首作品使用独立文件夹。
- 音频修改时间早于最新 CPR 修改时间时显示“早于工程修改”，这是时间戳提示，不判断实际内容是否过期。同名不同格式的音频分别保留。
- 文件离线会显示警告；恢复磁盘后手动刷新。移动／重命名工程子文件夹后，备注不会自动迁移到新的工程路径。
- 无删除工程功能。取消外部音频关联、移除资料库位置均不删除磁盘上的文件。
- 当前构建使用本机临时签名，未作 Apple Developer ID 签名／公证。

## 资料存放

资料库保存在 `~/Library/Application Support/CubaseShelf/library.json`。这里保存位置书签、工程索引和你填写的备注、评分等。可备份这个文件。应用不上传资料，不改变 CPR、BAK 或原音频。

仓库和下载包不包含音乐工程、录音、试听音频或个人资料库。请添加自己的工程目录。右键侧栏工程位置可以移除索引，不删除磁盘文件。

## 源码与编译

`Source/` 包含完整 Swift 源码；没有外部依赖。安装 Xcode Command Line Tools 后，在本目录执行：

```sh
bash build.sh
bash test.sh
```

本机已用 Swift 6.1.2 的 Swift 5 语言模式构建，目标为 `arm64-apple-macosx13.0`。默认编译缓存位于本目录 `.build`；可用 `CUBASESHELF_BUILD_DIR` 指定其他路径。

默认测试自动生成临时目录和模拟文件，不需要私人素材。也可传入自己的工程目录进行只读扫描和音频解码测试：

```sh
bash test.sh /path/to/test-project
```

如果终端运行环境禁止系统音频解码服务，可先执行文件系统测试，并在正常桌面会话中验证音频：

```sh
bash test.sh /path/to/test-project --filesystem-only
```

详见 [验证记录](验证记录.md)。
